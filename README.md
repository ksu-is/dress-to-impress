# dress-to-impress
## About the Project
Dress to Impress is a fashion game I'm creating using Python and Tkinter. Players will get a random fashion theme and choose outfits to match it. Once they finish, they'll receive a score based on their outfit choices.

## Features
- Random fashion themes
- Different clothing options
- Buttons to select outfits
- A scoring system
- A fun and colorful interface

## Tools
- Python
- Tkinter
- Visual Studio Code

## Project Goal
My goal is to create a simple and interactive fashion game while practicing the Python skills I've learned in class.
